# AM_UMI 项目摘要

> 更新：2026-09-24。这里是当前结论的短版；实验过程、历史踩坑、配置与证据统一保存在 [PROJECT_PROGRESS.md](https://github.com/Zzzuuu111/AM_UMI/blob/am-umi-docs/umi/PROJECT_PROGRESS.md)。两份文档如有出入，以详细档案中日期较新的实测记录为准。

## 项目在做什么

用手持 V 型夹爪和腕部相机录制桌面操作示教，处理成图像、末端位姿和夹爪宽度，训练 UMI 风格的视觉动作策略，最终由 AM2Pro 执行。当前任务是从固定起点靠近并夹取左侧物体，搬到右侧放下。**现阶段重点是训练和离线验证；模型尚未证明能自主完成实机任务。**

当前使用 EMEET 相机的手持 V 型夹爪方案。Osmo Action 4 是历史试验路线，相关问题保留在详细档案。IMU 主要关系到相机位姿估计和建图；当前策略训练的观测以相机图像和机器人状态为主，不能把“有 IMU”理解为模型直接获得了动作意图。

## 已经做到哪里

| 环节 | 当前结果 |
|---|---|
| 数据 | V12 数据集有 **30 条示教、13,335 帧**；按完整示教划分为 28 条训练、2 条验证。已完成数据格式和离线质量检查。 |
| 已知轨迹回放 | 手持轨迹到 AM2Pro 的任务点转换、离线 IK 和受保护的空载 replay 已有通过案例。这验证的是**已知示教轨迹的回放链路**。 |
| 策略训练 | 已训练采用 CLIP 预训练 ViT-Base 视觉编码器的模型，保存至 **epoch 140** 后暂停；其动作 Transformer 仍从头训练。该运行的 checkpoint 含完整续训状态，训练总目标为 200 epochs。 |
| 策略离线推理 | epoch 140 在各抽 32 个窗口的评估中，位置 RMSE 中位数为训练集 **5.77 mm**、验证集 **13.53 mm**；明显优于之前的小型从头训练配置，但部分验证窗口仍出现大误差。 |

上述误差比较的是模型预测的未来 TCP 动作和数据标签，发生在 IK 与机器人执行之前；它**不是**实机成功率。训练与评估细节见 [详细档案第 16.11 节](https://github.com/Zzzuuu111/AM_UMI/blob/am-umi-docs/umi/PROJECT_PROGRESS.md)。

## 当前主要问题与判断

1. **验证集部分窗口预测明显不对。** demo 054 的 sample 475：标签在约 1.5 秒内最大移动 13.64 mm、夹爪保持张开，模型却预测较大移动和闭合。不同 checkpoint 和扩散种子下仍有较大误差。画面及标签对照保存在本机 `data/outputs/vjaw_original30_pretrained_20260923_151807/review_val_demo054_epoch140/observation_context_475_503.png`；训练输出未上传 GitHub。
2. **训练覆盖与动作一致性更值得优先处理。** 与 sample 475 类似的“张开且短时间近静止”目标，在 11,117 个训练窗口中只有 20 个重叠窗口，来自 4 条示教；相近画面有时又对应移动并闭合的后续动作。单看当前画面，模型不一定能判断下一步意图。检查过程见 [详细档案第 16.14 节](https://github.com/Zzzuuu111/AM_UMI/blob/am-umi-docs/umi/PROJECT_PROGRESS.md)。
3. **单纯延长这批数据的训练，收益目前不明显。** epoch 100–140 的验证位置误差基本持平；开头缺少历史图像也无法单独解释后续窗口的大误差。数据标签的绝对精度和时间同步仍需继续核查，不能把根因定为某一项。对照结果见 [详细档案第 16.12–16.13 节](https://github.com/Zzzuuu111/AM_UMI/blob/am-umi-docs/umi/PROJECT_PROGRESS.md)。

“30 条够不够”没有固定答案。对当前任务，更重要的是每条示教的轨迹和夹爪标签可靠，以及关键动作阶段有足够多的**独立、动作明确**的例子。更多重复窗口不能代替独立示教。

## 接下来按什么顺序做

1. 复查高误差窗口的原视频、相机输入、TCP 和夹爪标签，特别是画面相近但后续动作不同的片段。
2. 有针对性地补录完整示教：在已验证的起点和工作区内覆盖物体位置、靠近、停顿、夹取、搬运、放下；相同任务阶段尽量保持动作意图一致。每条都通过既定的数据质量、离线 IK 和空载回放门槛后再纳入正式集合。
3. 保留**整条未参与训练**的示教做验证，沿用相同的离线指标，对比新旧模型与典型失败窗口；不要只看训练损失。
4. 离线预测、标签和执行链路分别过关后，再将策略输出接入 TCP 变换、连续 IK、限位保护，进行低速、空载、人工监督的实机测试。当前没有策略闭环成功的证据。

详细命令、实验记录、配置差异、续训方法和历史踩坑均在 [PROJECT_PROGRESS.md](https://github.com/Zzzuuu111/AM_UMI/blob/am-umi-docs/umi/PROJECT_PROGRESS.md)。后续新增实测先写入详细档案，再同步更新本摘要中的当前结论。
